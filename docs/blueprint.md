# **App Name**: JobFit AI

## Core Features:

- Resume Upload & Job Description Input: Users can upload their resume in PDF format and input the target job description text.
- ATS Compliance Analysis Tool: An AI-powered tool that analyzes the uploaded resume against the job description for ATS formatting and keyword conditions, identifying potential parsing issues.
- Keyword Density Analysis: Evaluate how frequently job-specific keywords appear in the resume compared to the job description, suggesting adjustments for optimal keyword usage.
- ATS Score & Match Evaluation: Provides an overall ATS compatibility score and indicates the resume's alignment with the job description requirements.
- Improvement Insights Tool: An AI tool that highlights weak areas, identifies specific issues in the resume, and offers actionable solutions to optimize for ATS and recruiter impact.
- Formatting & Layout Compliance: Detects formatting issues (like tables, graphics, unusual fonts) that may hinder ATS parsing and suggests clean, ATS-friendly alternatives.
- AI-Powered Bullet Point Suggestions Tool: Provides auto-generated suggestions for bullet points and phrasing improvements aligned with the job description to enhance impact and clarity.

## Style Guidelines:

- Scheme: Light. Emphasizes clarity and readability suitable for analytical content.
- Primary color: A sophisticated, deep blue-purple (#40268F) for professionalism and insight.
- Background color: A very light, almost white with a subtle blue-purple tint (#F2F1F8) to maintain a clean and crisp aesthetic.
- Accent color: A vibrant, clear blue (#248EC0) used for interactive elements and key highlight indicators, providing a professional contrast.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, technical, and precise feel.
- Body font: 'Inter' (sans-serif) for high readability and a neutral, objective presentation of analysis and suggestions.
- Utilize modern, clean line-art icons that visually communicate concepts such as upload, analysis, score, and recommendations, maintaining a professional look.
- A clean, multi-column layout with ample whitespace to clearly separate input sections, analytical results, and actionable recommendations. Prioritize content hierarchy.
- Subtle loading animations and transition effects to provide smooth user feedback during resume processing and section changes, enhancing user experience without distraction.
